# vConsole
**vConsole** - A lightweight, extendable front-end developer tool for mobile web pages

## Demo 
Browse it on your phone: http://wechatfe.github.io/vconsole/demo.html

Usage Instructions for [Via](https://viayoo.com/en/) Browser

1. ​Open Via Browser.
2. ​Navigate to `Settings` > `Scripts`.
3. Enable `Enable scripts`.
4. Click `+` > `New Script`.
5. Paste the code provided above [vconsole.user.js]([https://raw.githubusercontent.com/haithamaouati/Eruda/main/eruda.user.js](https://raw.githubusercontent.com/haithamaouati/vConsole/main/vconsole.user.js)) and save.

Usage Instructions for [Soul](https://play.google.com/store/apps/details?id=com.mycompany.app.soulbrowser&hl=en) Browser

1. ​Open Soul Browser.
2. ​Navigate to `Settings` > `Web content`.
3. Enable `Use UserScript` > `UserScript list`.
4. Click `+` > `Direct input`.
5. Paste the code provided above [vconsole.user.js](https://raw.githubusercontent.com/haithamaouati/vConsole/main/vconsole.user.js) and save.

Import script from URL:
```
https://raw.githubusercontent.com/haithamaouati/vConsole/main/vconsole.user.js
```

> [!TIP]
> Click the lower right corner `vConsole` button to get start.
